# Formulário de Cadastro de DEVs

Exercício de HTML e CSS para treinar formulários: uma página de cadastro de desenvolvedores com vários tipos de campo.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

## Campos do formulário

| Campo | Tipo |
| --- | --- |
| Nome e sobrenome | Texto, obrigatórios |
| Email | Email, obrigatório |
| De qual lado da aplicação você desenvolve? | Seleção com opções Front-end, Back-end e Fullstack |
| Senioridade | Lista de seleção com Junior, Pleno e Senior |
| Tecnologias que utiliza | Caixas de marcação com HTML, CSS, PHP, C#, Python, JavaScript e Java |
| Experiência | Área de texto |

## O que pratiquei

Os principais tipos de campo do HTML, os rótulos (`label`) ligados a cada campo, a separação visual com `fieldset` e a validação básica com o atributo `required`.

## Como visualizar

```bash
git clone https://github.com/GustavoBs12/Formulario.git
```

Depois, abra o arquivo `index.html` no navegador.

## Observação

Este projeto é só a parte visual: o formulário ainda não envia nem salva os dados.
